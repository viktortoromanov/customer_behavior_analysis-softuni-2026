# Customer Behavior Analysis 

A reusable Python notebook for analysing repeat customer purchases using transaction data.

## Project Overview

This project uses the Online Retail dataset to:

- Calculate repeat purchase rates.
- Compare customer groups by country.
- Apply Bernoulli and Binomial probability models.
- Interpret results and identify data limitations.

## Dataset

Online Retail dataset from the UCI Machine Learning Repository.

## Requirements

- Python 3
- pandas
- numpy
- matplotlib
- scipy
- openpyxl
- Jupyter Notebook

## How to Run

1. Install the required libraries.
2. Keep Online Retail.xlsx in the project folder.
3. Open customer_behavior_analysis_softuni_2026.ipynb
4. Run the notebook cells in order.

## Reusability

The notebook can be adapted to other transaction datasets by changing the configuration section, including customer ID , order ID, group column and repeat purchase threshold.
